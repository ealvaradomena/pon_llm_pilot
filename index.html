PON Governance LLM Pilot

Reconstructing the 2024 SBS protocol and comparing model generations

Repository purpose

This repository contains the computational materials associated with the manuscript Institutional Rules, Boundary Objects, and LLMs — A proof-of-concept for large-N research on the governance of purpose-oriented networks.

The revised principal analysis asks:

How does a newer model compare with the frozen 2024 GPT-4 Turbo responses when both are evaluated under the same reconstructed step-by-step (SBS) protocol?

The historical benchmark is the preserved Dec. 24, 2024 *_sbs.txt output. The newer arm uses the pinned gpt-5.4-nano-2026-03-17 snapshot. The original 2024 outputs are never regenerated or overwritten.

Study cases

The strict comparison uses IRG, EUHC, COAS, CAN, and CEER. BEREC remains part of the archival corpus but is handled separately because its preserved Dec. 23 output predates the final Dec. 24 request implementation.

Dedicated BEREC replication uses BO1B.txt, not BO1A.txt, and is excluded from the five-PON aggregate analysis.

Two linked reproductions

The repository separates two tasks:

  1. Manuscript Table A5 replication. HBM, ASC, JNG, and the frozen legacy SBS LLM reconstruct the historical four-coder agreement table over the manuscript’s 14 prompts.
  2. Extended SBS model comparison. The same human data and frozen legacy SBS outputs are compared with a new gpt-5.4-nano-2026-03-17 SBS run over the preserved 15-question computational instrument.

Project-facing outputs use explicit agreement labels such as 3 TRUE / 1 FALSE, and report directly whether each LLM agrees with the three-human majority vote.

Table A5 provenance

The surviving data reproduce 67 of 70 Table A5 cells. Three manuscript cells report 2-2 where the raw human + frozen LLM responses produce a 3-to-1 split: IRG prompt 3, cOAlition S prompt 8, and CEER prompt 6. These are retained as documented Table A5 errors; no underlying response is altered.

See 2024 Replication and provenance/TABLE_A5_REPLICATION.md.

Reproducibility architecture

The repository separates:

  • frozen 2024 evidence in root-level output/ files;
  • new SBS model runs in timestamped directories under output/current/, with completed runs explicitly marked by run_manifest.json and partial/failed runs retained as run_failed.json;
  • dedicated BEREC runs under output/berec_replication/;
  • archival improved-protocol materials under output/improved/; and
  • derived tables and figures under derived/.

For execution instructions and API safeguards, see README.md.

## Repository purpose

This repository contains the computational materials associated with the manuscript *Institutional Rules, Boundary Objects, and LLMs — A proof-of-concept for large-N research on the governance of purpose-oriented networks*.

The revised principal analysis asks:

> **How does a newer model compare with the frozen 2024 GPT-4 Turbo responses when both are evaluated under the same reconstructed step-by-step (SBS) protocol?**

The historical benchmark is the preserved Dec. 24, 2024 `*_sbs.txt` output. The newer arm uses the pinned `gpt-5.4-nano-2026-03-17` snapshot. The original 2024 outputs are never regenerated or overwritten.

## Study cases

The strict comparison uses **IRG, EUHC, COAS, CAN, and CEER**. BEREC remains part of the archival corpus but is handled separately because its preserved Dec. 23 output predates the final Dec. 24 request implementation.

Dedicated BEREC replication uses `BO1B.txt`, not `BO1A.txt`, and is excluded from the five-PON aggregate analysis.

## Two linked reproductions

The repository separates two tasks:

1. **Manuscript Table A5 replication.** HBM, ASC, JNG, and the frozen legacy SBS LLM reconstruct the historical four-coder agreement table over the manuscript's 14 prompts.
2. **Extended SBS model comparison.** The same human data and frozen legacy SBS outputs are compared with a new `gpt-5.4-nano-2026-03-17` SBS run over the preserved 15-question computational instrument.

Project-facing outputs use explicit agreement labels such as `3 TRUE / 1 FALSE`, and report directly whether each LLM agrees with the three-human majority vote.

## Table A5 provenance

The surviving data reproduce 67 of 70 Table A5 cells. Three manuscript cells report `2-2` where the raw human + frozen LLM responses produce a 3-to-1 split: **IRG prompt 3, cOAlition S prompt 8, and CEER prompt 6**. These are retained as documented Table A5 errors; no underlying response is altered.

See [2024 Replication](reports/results.qmd) and `provenance/TABLE_A5_REPLICATION.md`.

## Reproducibility architecture

The repository separates:

- frozen 2024 evidence in root-level `output/` files;
- new SBS model runs in timestamped directories under `output/current/`, with completed runs explicitly marked by `run_manifest.json` and partial/failed runs retained as `run_failed.json`;
- dedicated BEREC runs under `output/berec_replication/`;
- archival improved-protocol materials under `output/improved/`; and
- derived tables and figures under `derived/`.

For execution instructions and API safeguards, see `README.md`.
