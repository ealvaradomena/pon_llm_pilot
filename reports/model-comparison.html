Frozen GPT-4 Turbo versus a newer pinned model under the same protocol

Design

This comparison changes model generation only. Both arms use the same reconstructed Dec. 24, 2024 SBS protocol and the same five PONs.

Model Status
GPT-4 Turbo Frozen 2024 *_sbs.txt responses; never rerun
gpt-5.4-nano-2026-03-17 New SBS run under output/current/

The improved-protocol experiment and plain-zero-shot outputs are archival/secondary and are not pooled into this analysis. The comparison pipeline considers only newer-model run directories containing run_manifest.json with status == "complete"; a directory carrying run_failed.json, or lacking an explicit completed manifest, is not treated as a completed result.

Across the 75 PON-question classifications, the frozen GPT-4 Turbo SBS responses agreed with the confirmed human reference in 86.7% of cases, compared with 78.7% for GPT-5.4 nano. This is a -8.0 percentage-point change in agreement for the newer model.

Changing model generation altered 14 of 75 classifications (18.7%). Of those changes, 4 moved toward the human reference and 10 moved away.

The result is descriptive of this fixed five-PON, 15-question comparison. It does not establish that one model generation is generally superior across other tasks, prompts, or domains.

The comparison script now enforces the expected analytical cardinality before writing results: 75 decisions per model, 15 decisions per model/PON, one row per model/PON/question key, 75 direct model-to-model comparisons, and a common human-reference value for each paired decision. The new-model response is scored only when exactly 15 binary classifications are recoverable. Historical outputs remain untouched regardless of parsing or scoring results.

```{r}
#| label: setup
#| include: false
library(dplyr)
library(knitr)
library(readr)

paths <- list(
  overall = "derived/sbs_model_metrics_overall.csv",
  by_pon = "derived/sbs_model_metrics_by_pon.csv",
  stability = "derived/sbs_model_stability_overall.csv",
  flips = "derived/sbs_model_flip_audit.csv",
  coder = "derived/sbs_coder_comparison_extended.csv",
  diagnostics = "derived/sbs_output_format_diagnostics.csv"
)
comparison_ready <- all(file.exists(unlist(paths)))

if (comparison_ready) {
  overall <- readr::read_csv(paths$overall, show_col_types = FALSE)
  by_pon <- readr::read_csv(paths$by_pon, show_col_types = FALSE)
  stability <- readr::read_csv(paths$stability, show_col_types = FALSE)
  flips <- readr::read_csv(paths$flips, show_col_types = FALSE)
  coder <- readr::read_csv(paths$coder, show_col_types = FALSE)
  diagnostics <- readr::read_csv(paths$diagnostics, show_col_types = FALSE)

  legacy_accuracy <- overall |>
    dplyr::filter(.data$model_id == "gpt-4-turbo") |>
    dplyr::pull(.data$accuracy)
  current_accuracy <- overall |>
    dplyr::filter(.data$model_id == "gpt-5.4-nano-2026-03-17") |>
    dplyr::pull(.data$accuracy)
  accuracy_change_pp <- 100 * (current_accuracy - legacy_accuracy)

  flip_summary <- flips |>
    dplyr::filter(.data$changed) |>
    dplyr::count(.data$direction, name = "n")

  changed_n <- sum(flips$changed)
  toward_n <- flip_summary |>
    dplyr::filter(.data$direction == "Toward human") |>
    dplyr::summarise(n = sum(.data$n)) |>
    dplyr::pull(.data$n)
  away_n <- flip_summary |>
    dplyr::filter(.data$direction == "Away from human") |>
    dplyr::summarise(n = sum(.data$n)) |>
    dplyr::pull(.data$n)

  by_pon_display <- by_pon |>
    dplyr::select(pon, model_id, accuracy) |>
    tidyr::pivot_wider(names_from = model_id, values_from = accuracy) |>
    dplyr::mutate(
      change_pp = 100 * (
        .data[["gpt-5.4-nano-2026-03-17"]] -
          .data[["gpt-4-turbo"]]
      )
    )
}
```

## Design

This comparison changes **model generation only**. Both arms use the same reconstructed Dec. 24, 2024 SBS protocol and the same five PONs.

| Model | Status |
|---|---|
| GPT-4 Turbo | Frozen 2024 `*_sbs.txt` responses; never rerun |
| `gpt-5.4-nano-2026-03-17` | New SBS run under `output/current/` |

The improved-protocol experiment and plain-zero-shot outputs are archival/secondary and are not pooled into this analysis. The comparison pipeline considers only newer-model run directories containing `run_manifest.json` with `status == "complete"`; a directory carrying `run_failed.json`, or lacking an explicit completed manifest, is not treated as a completed result.
