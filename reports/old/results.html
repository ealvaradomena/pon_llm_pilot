Legacy Results

Evaluation of the preserved December 2024 final-pipeline outputs

Scope

This report evaluates the ten response files preserved from the Dec. 24, 2024 final pipeline. It does not call OpenAI and does not modify any historical output.

BEREC is not inserted into this human-reference evaluation because its surviving Dec. 23 file comes from an earlier development stage and there is no recovered 15-question BEREC human-reference vector tied unambiguously to that output. BEREC remains part of the source corpus and is handled explicitly in the model-generation comparison.

```{r}
#| label: setup

library(dplyr)
library(ggplot2)
library(knitr)
library(purrr)
library(readr)
library(tidyr)
library(tibble)

source("R/analysis.R")
questions <- readr::read_csv(
  "input/reference/questions.csv",
  show_col_types = FALSE
)
human <- readr::read_csv(
  "input/reference/legacy_human_responses.csv",
  show_col_types = FALSE
)

files <- tibble::tribble(
  ~entity, ~entity_slug, ~technique, ~path,
  "Independent Regulators Group", "irg", "Zero-shot", "output/BO2A-2024-12-24-2-52-18_irg_z.txt",
  "Independent Regulators Group", "irg", "Step by step", "output/BO2A-2024-12-24-2-55-3_irg_sbs.txt",
  "EU Health Coalition", "euhc", "Zero-shot", "output/BO3A-2024-12-24-2-53-29_euhc_z.txt",
  "EU Health Coalition", "euhc", "Step by step", "output/BO3A-2024-12-24-2-55-18_euhc_sbs.txt",
  "cOAlition S", "coas", "Zero-shot", "output/BO4A-2024-12-24-2-53-56_coas_z.txt",
  "cOAlition S", "coas", "Step by step", "output/BO4A-2024-12-24-2-55-51_coas_sbs.txt",
  "Climate Action Network", "can", "Zero-shot", "output/BO5A-2024-12-24-2-54-17_can_z.txt",
  "Climate Action Network", "can", "Step by step", "output/BO5A-2024-12-24-2-56-12_can_sbs.txt",
  "Council of European Energy Regulators", "ceer", "Zero-shot", "output/BO6A-2024-12-24-2-54-38_ceer_z.txt",
  "Council of European Energy Regulators", "ceer", "Step by step", "output/BO6A-2024-12-24-2-56-33_ceer_sbs.txt"
)

evaluation <- purrr::pmap_dfr(
  files,
  function(entity, entity_slug, technique, path) {
    evaluate_output(
      path,
      entity_slug,
      technique,
      questions,
      human
    ) |>
      dplyr::mutate(entity = entity)
  }
)

metrics <- evaluation |>
  dplyr::group_by(.data$entity, .data$technique) |>
  dplyr::group_modify(~ compute_metrics(.x)) |>
  dplyr::ungroup()
```

## Scope

This report evaluates the ten response files preserved from the Dec. 24, 2024 final pipeline. It does not call OpenAI and does not modify any historical output.

BEREC is not inserted into this human-reference evaluation because its surviving Dec. 23 file comes from an earlier development stage and there is no recovered 15-question BEREC human-reference vector tied unambiguously to that output. BEREC remains part of the source corpus and is handled explicitly in the model-generation comparison.

## Disagreements with the human reference

```{r}
#| label: fig-errors
#| fig-cap: "Disagreements with the recovered human-reference labels"
#| fig-height: 4.5

error_counts <- evaluation |>
  dplyr::filter(!.data$agreement) |>
  dplyr::count(.data$entity, .data$technique, name = "disagreements")

ggplot2::ggplot(
  error_counts,
  ggplot2::aes(
    x = .data$entity,
    y = .data$disagreements,
    fill = .data$technique
  )
) +
  ggplot2::geom_col(position = "dodge") +
  ggplot2::labs(
    x = NULL,
    y = "Disagreements",
    fill = "Prompt condition"
  ) +
  ggplot2::theme_minimal(base_size = 11) +
  ggplot2::theme(
    axis.text.x = ggplot2::element_text(
      angle = 25,
      hjust = 1
    )
  )
```
